# Воспроизведение Sparse Attention as Compact Kernel Regression

Статья связывает разреженное внимание с ядерной регрессией компактного носителя.
Тесты используют Memory Mosaics.


| Ядро в тесте | Ядро регрессии                         |
| ------------ | -------------------------------------- |
| softmax      | Гауссово                               |
| sparsemax    | Нормированное Epanechnikov             |
| entmax15     | Biweight                               |
| entmax43     | Triweight                              |
| norm_relu    | Epanechnikov с порогом 0               |
| topk         | Усечённое гауссово, k ближайших ключей |


Код повторяет схему [Library](https://github.com/facebookresearch/MemoryMosaics/tree/main/Library) из Memory Mosaics.  
Замена ядра действует только в контекстном внимании.  
Долговременная память по-прежнему использует softmax.  
В модели нет позиционных эмбеддингов.  
Маска внимания каузальная и закрывает диагональ.  
Каждый вектор значения использует следующий токен.

конфигурация системы

```
Графический процессор — NVIDIA GeForce RTX 5070 с памятью 12 ГБ.
Операционная система — Windows.
Версия Python — 3.14.
Версия PyTorch — 2.14.0+cu130.
```

## Запуск теста

1. Откройте терминал в корневой папке репозитория.
2. Выполните одну цель из Makefile.


| Задача                    | Цель                     |
| ------------------------- | ------------------------ |
| MQMTAR, малый тест        | `make hw2-mqmtar`        |
| MQMTAR, средний тест      | `make hw2-mqmtar-scaled` |
| MQMTAR, 10,2 млн примеров | `make hw2-mqmtar-budget` |
| Reverse                   | `make hw2-reverse`       |
| Sort                      | `make hw2-sort`          |
| RegBench                  | `make hw2-regbench`      |
| Кривые                    | `make hw2-tb`            |


## Условия тестов

Каждый тест в этом отчёте использует 1 сид.
Статья для синтетических задач берёт среднее по 3 сидам.
Точное совпадение считает 256 примеров на каждую длину.
Ответ верный только тогда, когда верны все целевые токены.
Третий знак после запятой на этой выборке неустойчив.

Оптимизатор — AdamW, если раздел не даёт другое значение.
Скорость обучения равна 0,001.
Weight decay равен 0,1.
Коэффициенты AdamW равны 0,9 и 0,95.
Dropout равен 0.

Число слоёв совпадает со статьёй.

## MQMTAR

MQMTAR хранит много пар ключ–значение в одной последовательности.
Каждый ключ состоит из 2 токенов.
Каждое значение состоит из 2 токенов.
Модель должна ответить на 4 запроса.
Точное совпадение равно 1 только тогда, когда верны все 8 токенов ответа.

## RegBench

Каждый пример содержит строки одного случайного автомата.
В автомате от 4 до 8 состояний.
В алфавите 8 символов.
Из каждого состояния выходит 1, 2 или 3 ребра.
Следующий символ — равномерная выборка по этим рёбрам.
В каждом примере от 8 до 12 строк.
В каждой строке от 2 до 6 символов.
Строки разделяет служебный токен.
В обучающем наборе 2000 автоматов.
В тестовом наборе 256 автоматов.
Эти два набора не имеют общего автомата.

В модели 2 слоя, ширина 128 и 8 голов.
В долговременной памяти 448 слотов.
Размер батча равен 32.
Скорость обучения равна 0,0005.
Число шагов равно 4000.
В статье в наборах до 40000 примеров.
Обучение может занимать 200 эпох.
Статья также выбирает глубину и ширину перебором.

Accuracy — доля примеров с верным последним символом.
TVD — среднее половинное расстояние L1 между распределением softmax и равномерным распределением на разрешённых рёбрах.
Обе оценки лежат в диапазоне от 0 до 1.
Статья часто записывает эти оценки в процентах.

Все шесть ядер закончили 4000 шагов.


| Ядро      | Accuracy | TVD    |
| --------- | -------- | ------ |
| softmax   | 0,4492   | 0,4835 |
| sparsemax | 0,4805   | 0,4798 |
| norm_relu | 0,4062   | 0,4897 |
| topk      | 0,4531   | 0,4738 |
| entmax15  | 0,4414   | 0,4711 |
| entmax43  | 0,4609   | 0,4788 |


Значения accuracy лежат между 0,4062 и 0,4805.
Значения TVD лежат между 0,4711 и 0,4897.
Accuracy ядра norm_relu — наименьшее значение.
Accuracy ядра sparsemax — наибольшее значение.
Таблица 1 статьи показывает то же направление в колонках с малым числом данных.
Разница в этом тесте мала.
